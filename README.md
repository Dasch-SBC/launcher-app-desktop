# launcher-app-desktop
to help users open several apps or programs with one click on the desktop

first install pyinstaller library, "pip install pyinstaller" paste this code to install on your terminal

how to use the program :
1. install python
2. download file "launcher .py"
3. edit in code editor
4. extract to exe with pyinstaller with code in terminal or cmd in your launcher folder "pyinstaller --onefile nameFile.py"
5. the results of the file extraction are in the /dist folder in your launcher folder.
6. example "launcher.exe"
